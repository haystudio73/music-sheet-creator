MusicXML Editor

Select a note: A–G sets pitch, =/− transposes, comma/period changes duration. Use Smoosic’s menus for measures, lyrics and layout, then Save to project.

Editor edits are saved as a separate MusicXML version in this project. The transcription and its exports stay at the checked source revision.

Editor playback uses the bundled piano sound for all instruments.
