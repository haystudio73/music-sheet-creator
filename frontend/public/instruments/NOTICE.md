# FluidR3 General MIDI samples

Source: Benjamin Gleitzman, MIDI.js Soundfonts, https://github.com/gleitz/midi-js-soundfonts

FluidR3_GM soundfont: Frank Wen and Fluid contributors. The upstream repository identifies the Fluid soundfont as Creative Commons Attribution 3.0: https://creativecommons.org/licenses/by/3.0/

These MP3 samples were rendered upstream from FluidR3_GM.sf2. For this application, the JavaScript data assignments were converted to plain JSON without executing them; sample audio is unchanged. See manifest.json for source URLs and SHA-256 checksums. Six instrument banks are included for offline listening. Attribution does not imply endorsement.
